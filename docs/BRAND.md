# Brand and interface direction

## Position

Matthematical Kalma is a deliberately over-serious name for a private sports intelligence tool shared by two friends. The interface can feel energetic and familiar without presenting itself as a bookmaker.

The wordmark is always lowercase, bold and italic. `matthematical` is white and `kalma` is yellow; the compact `mk` mark follows the same white/yellow split.

## Visual direction

The visual language takes broad inspiration from Australian mobile sportsbook conventions:

- saturated blue application chrome;
- bright yellow decision and value highlights;
- white cards on a pale blue-grey canvas;
- dense information presented in short, scannable blocks;
- rounded controls and pill-shaped segmented navigation;
- bold, compact sans-serif typography; and
- persistent thumb-friendly mobile navigation.

This is inspiration, not imitation. Do not copy third-party logos, icons, promotional artwork, slogans, mascots, bonus mechanics, or proprietary typefaces.

## Palette

| Token | Value | Purpose |
|---|---:|---|
| Blue | `#0867AD` | Primary chrome and navigation |
| Dark blue | `#003E6B` | Secondary surfaces |
| Deep blue | `#002F52` | Model and position surfaces |
| Yellow | `#FFDF00` | Best price, selected state and high-value actions |
| Green | `#54C85B` | Confirmed or healthy state only |
| Red | `#F20A45` | Alert, loss or blocked state only |
| Paper | `#EDF4F8` | Application background |

## Typography

Use a system sans-serif stack to keep the product fast and legible. Headings use heavy weight, tight tracking and short lines. Numeric odds and probabilities should be tabular where available. Avoid decorative type in data surfaces.

## Mobile-first rules

- Design at 375px before adapting to larger screens.
- Primary touch targets are at least 44px high.
- Keep key prices, edge and action on one card without horizontal scrolling.
- Pin the five-item navigation to the bottom safe area.
- Use horizontal scrolling only for secondary sport filters.
- Do not hide risk, uncertainty or source freshness to save space.
- Desktop should expand the same information hierarchy rather than introduce a separate experience.
